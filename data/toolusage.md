# 📌 チャンピオン対策Markdown 生成パイプライン運用マニュアル 兼 拡張設計書

## 1. ユーザーマニュアル（日常の運用フロー）

本パイプラインは、「手作業のキュレーション（戦術）」**と**「Riot公式の正確なデータ（CC・CD・数値）」を結合し、LLM（NotebookLMなど）へ提供するソースファイル（カンペ）を生成・保守するために使用します。日常のプレイからパッチ更新時まで、以下の3つのフェーズで使い分けます。

```
[champion_meta_mapping.json] (手動戦術/外部統計)
             │
             ├──► [generate_md.py] ◄── [Riot Data Dragon API] (公式数値/CC判定)
                         │
                         ▼
             [data/champion_md/*.md] (ロール別5ファイル)
                         │
                         ▼
             [NotebookLM] (AIコーチングのソースとして与える)

```

### ① 日常のアップデート（メタJSONの編集）

対戦を通じて「このチャンピオンにはこう動くべきだ」と気づきを得た時や、特定の対面対策を書きたい時に行います。

* **編集対象ファイル**: `data/champion_meta_mapping.json`
* **作業内容**: VSCode等のエディタでファイルを開き、該当チャンピオンの項目を更新します。
```json
"Ahri": {
  "roles": ["Mid"],
  "meta_info": {
    "Mid": {
      "threat": 4, 
      "tactics": "E(チャーム)に当たるとWが止まるので、Eを見てからWを撃つ。",
      "core_builds": [["マリグナンス", "ストームサージ"]]
    }
  }
}

```


※ `tactics`（戦術）の記述がメインとなります。ビルドやパワースパイクが不明な場合は空配列 `[]` のままで問題ありません。

### ② メモのMarkdownへの反映（全件強制生成）

手動で `champion_meta_mapping.json` を編集した後は、その内容をMarkdownファイルへ反映させます。

* **実行コマンド**:
```bash
python generate_md.py

```


* **処理内容**: あなたが記述した戦術と、Riot公式から取得した最新のスキルデータ（CC自動判定など）がマージされ、`data/champion_md/` ディレクトリ配下に5つのロール別Markdownファイル（`Mid_Champions.md` など）が上書き生成されます。生成後、NotebookLM上の対応するファイルを差し替えます。

### ③ パッチ更新時の対応（差分更新モード）

2週間に1回、LoLの公式パッチが更新された（例: 16.15 → 16.16）タイミングで実行する、本ツールの最大の特徴です。

* **実行コマンド**:
```bash
python generate_md.py --diff

```


* **処理内容**:
1. 最新パッチのデータをRiot APIから自動で取得・キャッシュします。
2. 前回生成時のスナップショット（`.state.json`）と比較し、**「ステータス数値やスキル効果に変更（ナーフ/バフ）があったチャンピオン」だけを検出**します。
3. 変更があったチャンピオンが含まれるロールファイル**だけを自動的に再生成**します。
4. コンソールに `→ NotebookLM 再アップロード推奨: Top_Champions.md, Mid_Champions.md` と出力されるため、指定されたファイルのみをNotebookLM上で差し替えます（変更のないファイルはアップロード不要です）。



### ④ 新チャンピオン実装時（テンプレートの冪等追加）

LoLに新しいチャンピオンが追加された際に1回だけ実行します。

* **実行コマンド**:
```bash
python init_meta_json.py

```


* **処理内容**: Riotから新チャンピオンの内部名を取得し、`champion_meta_mapping.json` に空のテンプレート枠を自動挿入します。既に記述済みの既存チャンピオンのデータ（`tactics` など）は絶対に破壊・上書きされない安全設計（冪等）になっています。ロールがズレている場合は、スクリプト内の `OVERRIDES` に追記して再実行すれば修正されます。
